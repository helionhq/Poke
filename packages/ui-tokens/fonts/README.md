# Fonts

From the Doop canvas "Poke One" (its uploaded fonts, as WOFF2 in `src/`), converted for iOS by
`python scripts/convert-fonts.py` (fontTools):

- `OpenRunde-{Regular,Medium,Semibold,Bold}.otf`: the text face, weights 400–700.
- `Exposure-Regular.ttf`: the display face. The canvas's Exposure VAR has one axis (EXPO, not
  weight); this is its default instance, which is what every frame renders.

JetBrains Mono (tool names) comes from `@expo-google-fonts/jetbrains-mono`.
The repo is private; these files are committed as the brief asks.
